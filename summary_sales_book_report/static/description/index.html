Summary Sales Book Report

Generate a detailed Sales Book report in Excel with just a few clicks.

Summary Sales Book Report helps you generate a clean and structured Excel report of posted customer invoices for a selected date range. It provides important sales information in an easy-to-read format.

Key Features

📅 Date Range Filter

Select the From Date and To Date to generate the report for the required period.

📊 Excel Report

Generate the Sales Book directly in Excel format for easy sharing and record keeping.

🧾 Detailed Sales Information

The report includes:

  • Date
  • Invoice Number
  • Customer
  • Sales Account
  • Narration
  • Amount
  • VAT
  • Invoice Value

✨ Clean & Structured Layout

The generated Excel report is formatted with clear headings, columns, and two-decimal amount values.

How It Works

  1. Open Invoicing → Reporting → Sales Book Report.
  2. Select the required From Date and To Date.
  3. Click Generate Report.
  4. Download and open the generated Excel report.
