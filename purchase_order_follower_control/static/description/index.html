Purchase Order Follower Notification Control

Control unwanted follower notifications on Purchase Orders

Overview

This module helps control notifications sent to followers of Purchase Orders. It prevents unwanted Purchase Order notifications simply because a user is a follower, while preserving standard Odoo notification behavior for other documents.

Key Features

  • Controls follower notifications on Purchase Orders.
  • Prevents unwanted notifications to Purchase Order followers.
  • Works with the standard Odoo Purchase Order workflow.
  • Does not change notification behavior for other Odoo documents.
  • Lightweight with minimal configuration.
  • Compatible with Odoo 17 Community and Enterprise.

How It Works

Purchase Order → Follower / Approver → Notification filtering → Intended recipients

The module extends Odoo's standard mail notification mechanism and applies the filtering specifically to Purchase Orders.

Use Case

When a user is added as a follower or approver on a Purchase Order, they may receive notifications that are not relevant to them. This module helps reduce unnecessary Purchase Order notifications without changing the standard mail framework across Odoo.
