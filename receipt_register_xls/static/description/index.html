Receipt Register Report

Generate a clear receipt register in Excel with date and customer filters.

Receipt Register Report helps accounting users generate an Excel receipt register for posted customer receipts received through bank and cash journals. Select a date range and customers, then export the receipt details and total amount in XLSX format.

Key Features

📅 Date Range Filter

Generate the receipt register for any selected start date and end date.

👥 Customer Filter

Select one or multiple customers to generate a focused receipt register.

🏦 Bank & Cash Receipts

Include posted inbound customer payments recorded through bank and cash journals.

📊 Excel Export

Generate the receipt register in XLSX format for easy review, sharing, and further analysis.

🧾 Receipt Details

View receipt date, receipt number, customer, narration, destination account, state, and amount.

💰 Total Receipt Amount

The report automatically calculates and displays the total receipt amount for the selected period.

How It Works

  1. Open Invoicing → Reporting → Receipt Register.
  2. Select the required Date and Date End.
  3. Select one or more Customers.
  4. Click XLS to generate the report.
  5. Open the generated Excel file to review the receipt details and total amount.
